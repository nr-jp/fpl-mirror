# fpl-mirror

Hourly full-fidelity mirror of the public Fantasy Premier League API for one entry's analysis
pipeline. No credentials, no private data: every file here is a copy of a public endpoint.

Read files at `https://raw.githubusercontent.com/nr-jp/fpl-mirror/main/<path>`.

See the docstring at the top of `mirror.py` for the layout. `data/derived/meta.json` says when the
last fetch ran and which gameweek is current.
